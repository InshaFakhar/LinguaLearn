# 🌍 LinguaLearn

**LinguaLearn** is an AI-powered language learning mobile application built with **Flutter** and **Firebase**. It helps users improve their language skills through interactive learning, AI conversations, quizzes, flashcards, and progress tracking.

---

## ✨ Features

- 🔐 Secure User Authentication (Firebase Authentication)
- 🤖 AI Language Tutor Chatbot (Groq API)
- 📚 Flashcards for Vocabulary Learning
- 📝 Interactive Quizzes
- ❤️ Favorite Words Collection
- 📊 Learning Progress Tracking
- 🏆 Achievement & Gamification System
- 🔥 Daily Learning Heatmap
- 📈 Weekly Progress Reports
- 🔔 Local Notifications & Learning Reminders
- 🌐 Offline Learning Support (SQLite)
- 🗣️ Text-to-Speech (TTS)
- ☁️ Firebase Cloud Firestore Integration

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/InshaFakhar/LinguaLearn.git
```

### Open Project

```bash
cd LinguaLearn
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```

---

## 🔑 Configuration

This project uses Firebase and AI services.

Before running the project:

- Configure your own Firebase project.
- Add your `google-services.json` file.
- Configure your own Groq API Key securely (never hardcode API keys in public repositories).
